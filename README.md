Hangman Game 

This is a simple Hangman word-guessing game made with Python and Tkinter.

## About the Project

The player must guess the word which has been randomly chosen one letter at a time.

The game allows the player six chances to get the answer wrong. The player wins if they have managed to guess all of the letters before the number of attempts is used up.

## Features

* Random word selection
* Letter guessing
* 6 incorrect attempts
* Displays guessed letters
* Win and lose messages
* New Game button
* Simple graphical user interface

## Technologies Used

* Python
* Tkinter
* Random module

## How to Run

Ensure that Python has been installed.
2. Download the repository or clone it.
3. Open the project folder in VS Code.
4. Run:

```bash
python hangman.py
```
